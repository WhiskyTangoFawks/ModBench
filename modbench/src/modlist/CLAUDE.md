# modlist

modlist commands. The commands of the mods and separators in mod order: enable, disable, move,
separators, uninstall, create empty mod and mod sync. It hides an uninstall's mark on the downloaded
file the mod came from. It hands the Instance adapter each change in domain words, and names no file
of the mod manager's. It gets what it needs from the instance value as an argument, such as the
mods to sync.
