# modlist

modlist commands. The commands of the mods and separators in mod order: enable, disable, move,
separators, uninstall, create empty mod and mod sync. It hides an uninstall's mark on the downloaded
file the mod came from. It hands the Instance adapter each change in domain words, names no file of
the mod manager's, and gets what it needs from the instance value, such as the mods to sync, as an
argument.
